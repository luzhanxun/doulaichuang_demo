一、配色

剂量从 60 : 30 : 10 改为 60 / 22 / 13 / 5——中性 60%，暖品牌 22%，深色科技 13%，语义 5%。 问题从来不是比例，而是“蓝色同时承担了品牌与信息两种语义”。v3 把品牌交给珊瑚、把信息交给蓝， 两套语义不再互相稀释。色块徽标是对比度：≥ 4.5 : 1 可承载正文，3–4.5 : 1 只可用于大字或图形， < 3 : 1 不可承载任何文字。浅色徽标一律标注“深字”，即用 --ink-900 叠加在该色上的比值。

60 / 22 / 13 / 5 的落地方式

60% 中性：表面 / 文本 22% 落日珊瑚 13% 深色科技 5% 语义
深色块预算--ink-950 面积 ≤ 18%（hero / 深色页头 / 科技卡）
珊瑚白字只允许 --coral-700（5.74 : 1）及更深
深底暖色强调--coral-400（ink-950 上 7.59 : 1）
正文下限4.5 : 1　大字（≥ 19px / 700）3 : 1
后台 CMS.admin-shell 把 --action 切回 --blue-700，保持冷色秩序感

三、形状：圆角 / 阴影 / 间距

年轻化的主要抓手是“圆角变大、描边退场、阴影变双层、色温变暖”。v1 用 1px 淡线划分一切，看起来像政务官网； v2 让卡片靠阴影浮起；v3 把阴影调成暖调双层，卡片圆角从 16 提到 20，主按钮改成胶囊形。 1px 线只留给表格、列表分隔这类确实需要对齐的场合。

五、动效

动效只回答两个问题：“这一下发生了什么”和“我从哪来、到哪去”。只动 transform 与 opacity， 绝不动 width / height / top / left / margin——那会触发重排。下面每一行都可以点一下看效果。

时长阶梯

--dur-instant80ms
按压、开关、hover 换色
--dur-fast120ms
图标位移、tooltip、微反馈
--dur200ms
按钮、卡片、折叠展开（默认）
--dur-slow300ms
弹层进出、抽屉、toast
--dur-slower420ms
页面转场、列表逐项进入的总时长

六、图标

71 个内联 SVG 线性图标，统一 1.75 描边、圆角端点，随 currentColor 取色。 不用 emoji 当图标：emoji 在不同系统上字形不一致，也无法跟随主题色。
