# 斗来创 · 港澳青年乡创线上推广平台

面向港澳青年的斗门乡村创业推广平台设计原型。一端是微信小程序的内容与申请入口，一端是斗门区融媒体中心的内容管理与审核后台，两端共用同一套设计令牌与组件。

> 本仓库是**纯静态高保真原型**：无后端、无构建步骤、无第三方依赖。所有项目、资讯、政策、组织与用户数据均为虚构演示数据，正式内容须经甲方终审后发布。

| --- | --- |
| 平台名称 | 斗来创（港澳青年乡创线上推广平台） |
| 地域范围 | 广东省珠海市斗门区 |
| 目标用户 | 港澳青年创业者、港澳社团与乡创组织、区镇统战与融媒体工作人员 |
| 主办 / 承办 | 中共珠海市斗门区委统一战线工作部 / 珠海市斗门区融媒体中心 |
| 交付形态 | 微信小程序原型（14 屏）+ 后台管理原型（8 视图）+ 设计总览页 |

## 设计方向

设计总览页与两端源码头部写有同一份「方向契约」，是所有页面的取舍依据：

| 维度 | 约定 |
| --- | --- |
| THESIS 命题 | 一个让港澳青年看得懂、信得过、愿意迈出第一步的乡创入口；不是政务信息发布页。 |
| OWN-WORLD 自有世界 | 湾区青蓝承载政务可信度；暖橙只用于「青年此刻可行动」的位置；生态绿归属乡创本身；水乡波纹是唯一装饰语言，只出现在头图与图片占位里，不进入内容区。 |
| STORY 叙事 | 看见斗门 → 读懂机会 → 查清政策 → 找到组织 → 提交申请 → 等待反馈。 |
| FIRST VIEW 首屏 | 一句话说明平台是什么，紧跟三个可点内容入口与一条最新重大信息；不做轮播横幅、不做纯装饰大图。 |
| FORM 形态 | 小程序 390×844 内容优先单列；后台深青蓝侧栏 + 浅底工作区，状态先于装饰。 |

由此推导出两条贯穿全站的硬规则：

- **色彩即语义**：青蓝 = 可信（结构、导航、正文强调），生态绿 = 乡创（项目、组织、通过），暖橙 = 行动（待处理、重点推荐、提交）。橙色面积始终控制在 10% 以内。
- **状态先于装饰**：列表、卡片、详情都必须先回答「这条内容现在是什么状态」，装饰只服务于识别，不服务于氛围。

### 字体与字阶

- 中文使用系统字体栈（PingFang SC / Microsoft YaHei / Noto Sans SC），不加载 Web 字体，避免首屏阻塞与授权问题。
- 数字与编号使用 `--font-num`（SF Pro Display / DIN Alternate）并开启 `tabular-nums`，让编号、统计在列表中纵向对齐。
- 界面按 7 级字阶取值：页面标题 40 / 区块标题 22 / 卡片标题 15 / 正文 14 / 辅助 12.5 / 说明 11.5 / 元信息 10.5（单位 px）。
- 正文行高 1.6；资讯与政策正文为 14px / 1.95 且两端对齐，长文阅读不挤压。

### 图标

`assets/js/icons.js` 内置 71 个 24×24 线性图标（stroke 1.8、圆角端点、无填充），不使用图标字体，也没有外部 SVG 文件。

```html
<i data-icon="arrow-right"></i>
```

`DOMContentLoaded` 时 `DLC.hydrateIcons()` 会把所有 `[data-icon]` 替换为内联 SVG；图标名拼错时回退为 `info`，不会出现空白。图标统一继承 `currentColor`，换色只需改文字颜色。

### 共享组件（`assets/css/base.css`）

- 按钮：`btn` + `-primary` / `-accent` / `-secondary` / `-ghost` / `-soft` / `-danger` / `-green` / `-glass`，尺寸 `-sm` / `-lg` / `-block` / `-icon`。
- 标签：`tag` + `-blue` / `-green` / `-orange` / `-gray` / `-red` / `-warn` / `-outline`。
- 状态：`status` + `-published` / `-pending` / `-draft` / `-offline` / `-info`，带前置圆点，与后端状态一一对应。
- 表单：`input` / `select` / `textarea` / `check` / `switch` / `segmented`，含 `hint` 与 `err-msg`。
- 占位图：`.media` 用渐变 + SVG 水乡波纹生成抽象图，提供 `-blue` / `-green` / `-warm` / `-teal` / `-deep` 五种色调。原型不引用任何实拍图与官方标识，规避版权风险。
- 反馈：`notice`（warn / danger / green / neutral）、`empty`、`skeleton`、`toast`。

### 交互机制

- 前进用 `[data-go]`、返回用 `[data-back]`、轻提示用 `[data-toast]`，全部通过事件委托处理，页面内不写行内脚本。
- 返回栈最多保留 24 层，超出后丢弃最早的记录，避免长时间演示后栈过深。
- hash 路由：切屏时用 `history.replaceState` 同步 `#screen-id`，刷新后仍停留在当前屏，也便于把某一屏直接发给评审。
- 键盘操作：`←` / `→` 切换上一屏 / 下一屏，`Enter` / `Space` 触发卡片，适合投屏讲解。
- 详情页隐藏底部 tabbar，仅首页 / 项目 / 资讯 / 政策 / 我的五个一级页显示；首页与登录页使用深色状态栏。
- 表单 textarea 的 `maxlength` 会自动同步字数提示；chip 与 tab 为单选，切换只改选中态。

### 内容规则（摘自说明面板）

说明面板中的规则与页面文案一一对应，是内容运营的约束条件：

- 资讯与政策须经甲方终审后发布；标题与来源不可省略，不使用诱导性标题。
- 正文不得插入营销或导流内容；已下架内容在小程序端不可访问。
- 不得改写政策原文含义，文号与发文机关须与官方一致；要点仅作辅助理解，须标注「以原文为准」。
- 组织信息由后台维护，变更需留操作记录；入会状态与后台审核状态保持一致。
- 证件与联系方式仅用于资格审核，实名信息仅本人可见。
- 审核状态由后台驱动、前端只读；未通过需展示原因与再次申请入口。
- 联系对接提交即生成线索记录，并提示用户不得填写银行卡、密码等敏感信息。

## 业务闭环与状态约定

- **内容状态**：`草稿` → `待审核` → `已发布`，任一审核环节可「退回修改」，已发布内容可「下架」。
- **审核环节**：编辑撰写 → 平台初审 → 甲方终审 → 自动发布，全程留痕，审核记录包含审核人、时间、意见与剩余时限。初审通过不代表可对外发布，甲方终审（3 个工作日内）是发布前的必要环节。
- **入会申请**：`审核中` → `待终审` → `已通过` / `未通过`，承诺 5 个工作日内反馈。
- **组织状态**：`已上线` / `已下线`；**项目状态**：`招商中` / `合作运营` / `招募中`。
- **前端只读**：小程序上的状态标签全部由后台驱动，用户侧不提供状态修改入口。
- **联系对接**：项目与组织详情中的联系人默认遮蔽，登录后可见；提交对接需求后由工作人员 1–2 个工作日内跟进，且不收取任何费用。
- **演示数据规模**：106 条内容（产业项目 42 / 重大信息 36 / 港澳政策 28）、18 个组织、27 份入会申请，日期集中在 2026 年。

## 技术实现

| 层 | 实现 |
| --- | --- |
| 结构 | 单文件 HTML，小程序每屏一个 `<section class="screen" data-screen="...">`，后台每个视图一个 `<section class="view" data-view="...">` |
| 样式 | 原生 CSS + 自定义属性，`tokens.css` → `base.css` → 页面级样式三层 |
| 脚本 | 原生 JavaScript（IIFE），无框架、无打包 |
| 图标 | JS 内联 SVG 字符串，零额外请求 |
| 依赖 | 无 `package.json`、无构建产物、无第三方库 |

- 交互由 `data-*` 属性 + 事件委托驱动，没有全局状态管理；小程序切屏会写入 hash，后台则读取 hash 直接打开对应视图，方便评审时按链接定位。
- 可访问性：`aria-label`、`role="button"` + `tabindex="0"`、`:focus-visible` 焦点环、方向键切屏、`prefers-reduced-motion` 降级。
- 适配：总览页 ≤900 单列；小程序外壳 1240 / 920 / 520 三档降级，520 以下隐藏页面目录；后台 1180 / 900 / 620 三档，900 以下侧栏收为 64px 图标栏。

7. 是否使用斗门区视觉元素、地图或标识 —— 当前未使用任何官方标识。
8. 适配范围 —— 当前 后台 ≥1280 完整呈现，窄屏降级到 900。

## 已知限制

- 无后端与持久化：刷新即重置，提交、审核、上传、下载、搜索、分页均为前端模拟。
- 登录为演示态：任意密码可进入，不校验权限；角色矩阵只用于展示权限设计。
- 所有数据与人物姓名均为虚构；政策原文为示意文本，正式发布前必须替换为官方文件并核对文号。
- 图片位置统一使用水乡波纹占位，未使用斗门区地图、区徽或任何官方标识。
- 设计总览页目前只保留头图与「待甲方确认」两部分；`overview.css` 中色板、字阶、图标、页面清单等样式已就绪，可继续补充对应章节。

## 参与贡献

1. 新增页面时先在 `assets/js/miniprogram.js` 的 `ORDER` 与 `NOTES` 中注册，说明面板会自动生成目录项。
2. 颜色、圆角、阴影一律引用 `tokens.css` 中的令牌，不在页面样式里写裸色值。
3. 新增图标加入 `assets/js/icons.js` 的图标表，统一 24×24、stroke 1.8、无填充。
4. 提交前确认三端在 1280 / 900 宽度下均可正常浏览，且键盘可完成主要操作。
