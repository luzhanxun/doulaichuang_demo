# 斗来创 · 斗门机遇一站式对接平台

面向大湾区青年的斗门机遇对接平台设计原型。一端是微信小程序的六大模块内容入口，一端是斗门区融媒体中心的内容审核与运营后台，两端共用同一套设计令牌与组件。

> 本仓库是**纯静态高保真原型**：无后端、无构建步骤、无第三方依赖。所有项目、资讯、政策、组织、岗位、供需、活动与用户数据均为虚构演示数据，正式内容须经审核通过后发布。

| 项目 | 说明 |
| --- | --- |
| 平台名称 | 斗来创（斗门机遇一站式对接平台） |
| 地域范围 | 广东省珠海市斗门区 |
| 目标用户 | 大湾区青年、创业团队与求职者、青年组织与商协会、区镇统战与融媒体工作人员 |
| 主办 / 承办 | 中共珠海市斗门区委统一战线工作部 / 珠海市斗门区融媒体中心 |
| 交付形态 | 微信小程序原型（19 屏）+ 后台管理原型（11 视图）+ 设计总览页 |

小程序按**六大模块**组织信息：找到项目、找到信息、找到组织、找到工作、找到供需、找到活动。

## 快速开始

无需安装依赖，直接用浏览器打开 `src/index.html` 即可。图标由内联 SVG 注入，`file://` 协议下同样可以正常运行。

如需以 HTTP 方式预览：

```bash
# 在仓库根目录执行
python -m http.server 8080
# 打开 http://localhost:8080/src/
```

| 入口 | 路径 | 内容 |
| --- | --- | --- |
| 设计总览 | `src/index.html` | 设计方向说明与「待甲方确认」清单 |
| 小程序原型 | `src/miniprogram/index.html` | 19 屏可交互原型，390×844 设备框 + 页面目录 + 设计说明面板 |
| 后台原型 | `src/admin/index.html` | 11 个视图，登录遮罩 → 工作台 |

两个原型都支持 hash 直达，便于评审时逐屏对照，例如 `src/miniprogram/index.html#project-detail`、`src/admin/index.html#review`。

后台演示账号为 `chenjing@doulaichuang.cn`，密码任意；也可以点「直接进入工作台」跳过登录。

## 设计方向

设计总览页与两端源码头部写有同一份「方向契约」，是所有页面的取舍依据：

| 维度 | 约定 |
| --- | --- |
| THESIS 命题 | 一个让大湾区青年看得懂、信得过、愿意迈出第一步的斗门机遇入口；不是政务信息发布页。 |
| OWN-WORLD 自有世界 | 湾区青蓝承载政务可信度；暖橙只用于「青年此刻可行动」的位置；生态绿归属斗门的产业与生态底色；水乡波纹是唯一装饰语言，只出现在头图与图片占位里，不进入内容区。 |
| STORY 叙事 | 看见斗门 → 找到项目 → 找到信息 → 找到组织 → 找到工作 → 找到供需 → 找到活动 → 留下联系方式。 |
| FIRST VIEW 首屏 | 用可配置轮播图说明平台是什么，紧跟六个模块入口与一条宣传片；轮播文案与样式由后台配置，宣传片懒加载、不自动播放。 |
| FORM 形态 | 小程序 390×844 内容优先单列；后台深青蓝侧栏 + 浅底工作区，状态先于装饰。 |
| SCOPE 范围 | 小程序 19 屏（六大模块 + 账户与对接流程）、后台 11 视图；内容审核为单层。 |

由此推导出两条贯穿全站的硬规则：

- **色彩即语义**：青蓝 = 可信（结构、导航、正文强调），生态绿 = 产业与生态（项目、组织、通过），暖橙 = 行动（待处理、重点推荐、提交）。橙色面积始终控制在 10% 以内。
- **状态先于装饰**：列表、卡片、详情都必须先回答「这条内容现在是什么状态」，装饰只服务于识别，不服务于氛围。

### 字体与字阶

- 中文使用系统字体栈（PingFang SC / Microsoft YaHei / Noto Sans SC），不加载 Web 字体，避免首屏阻塞与授权问题。
- 数字与编号使用 `--font-num`（SF Pro Display / DIN Alternate）并开启 `tabular-nums`，让编号、统计在列表中纵向对齐。
- 界面按 7 级字阶取值：页面标题 40 / 区块标题 22 / 卡片标题 15 / 正文 14 / 辅助 12.5 / 说明 11.5 / 元信息 10.5（单位 px）。
- 正文行高 1.6；资讯与政策正文为 14px / 1.95 且两端对齐，长文阅读不挤压。

### 圆角、阴影、间距、动效、层级

| 类别 | 令牌 | 取值 |
| --- | --- | --- |
| 圆角 | `--r-xs` → `--r-2xl`、`--r-pill` | 6 / 8 / 12 / 16 / 20 / 28 / 999 px |
| 阴影 | `--sh-1` → `--sh-4` | 4 级极浅蓝调阴影，靠层级差表达浮起高度 |

`base.css` 统一处理了 `prefers-reduced-motion: reduce`，动效可被系统设置关闭。

### 图标

`src/assets/js/icons.js` 内置 71 个 24×24 线性图标（stroke 1.8、圆角端点、无填充），不使用图标字体，也没有外部 SVG 文件。

```html
<i data-icon="arrow-right"></i>
```

`DOMContentLoaded` 时 `DLC.hydrateIcons()` 会把所有 `[data-icon]` 替换为内联 SVG；图标名拼错时回退为 `info`，不会出现空白。图标统一继承 `currentColor`，换色只需改文字颜色。

### 共享组件（`src/assets/css/base.css`）

- 按钮：`btn` + `-primary` / `-accent` / `-secondary` / `-ghost` / `-soft` / `-danger` / `-green` / `-glass`，尺寸 `-sm` / `-lg` / `-block` / `-icon`。
- 标签：`tag` + `-blue` / `-green` / `-orange` / `-gray` / `-red` / `-warn` / `-outline`。
- 状态：`status` + `-published` / `-pending` / `-draft` / `-offline` / `-info`，带前置圆点，与后端状态一一对应。
- 表单：`input` / `select` / `textarea` / `check` / `switch` / `segmented`，含 `hint` 与 `err-msg`。
- 占位图：`.media` 用渐变 + SVG 水乡波纹生成抽象图，提供 `-blue` / `-green` / `-warm` / `-teal` / `-deep` 五种色调。原型不引用任何实拍图与官方标识，规避版权风险。
- 反馈：`notice`（warn / danger / green / neutral）、`empty`、`skeleton`、`toast`。

### 交互机制

- 前进用 `[data-go]`、返回用 `[data-back]`、轻提示用 `[data-toast]`，全部通过事件委托处理，页面内不写行内脚本。
- 返回栈最多保留 24 层，超出后丢弃最早的记录，避免长时间演示后栈过深。
- hash 路由：切屏时用 `history.replaceState` 同步 `#screen-id`，刷新后仍停留在当前屏，也便于把某一屏直接发给评审。
- 键盘操作：`←` / `→` 切换上一屏 / 下一屏，`Enter` / `Space` 触发卡片，适合投屏讲解。
- **首页轮播图**：`#heroCarousel` 提供左右按钮与指示点，手动切换、不自动轮播；每张图的标题、副标题、字号、字重、颜色与对齐由后台配置，前端通过 `--hc-*` CSS 变量渲染。
- **简 / 繁切换**：顶部「简 / 繁」一键切换，遍历文本节点与 `placeholder` 命中词典后替换；仅作用于静态界面元素，`[data-dynamic]` 标注的后台输出内容保持原文。
- **宣传片懒加载**：首屏只渲染封面与播放按钮，点击后才创建 `<video preload="none">` 并播放，不自动播放；演示环境未接入视频源时给出提示并恢复封面。
- 详情页隐藏底部 tabbar，仅首页 / 项目 / 信息 / 活动 / 我的五个一级页显示；首页与登录页使用深色状态栏。
- 表单 textarea 的 `maxlength` 会自动同步字数提示；chip 与 tab 为单选，切换只改选中态。

### 内容规则（摘自说明面板）

说明面板中的规则与页面文案一一对应，是内容运营的约束条件：

- 内容（项目 / 信息 / 岗位 / 供需 / 活动）须经**单层审核**后发布：新建或修改 → 审核 → 通过 / 不通过，任何一次修改都要重新审核。
- 加入组织为**提交 → 审批 → 通过 / 不通过**，承诺 5 个工作日内反馈。
- 供需留言与活动报名仅对已登录用户开放；联系人、联系方式默认遮蔽，登录后可见。
- 活动报名提交后由后台确认，名额满即停止报名；报名信息仅用于活动组织。
- 简繁体切换只覆盖静态界面元素，后台输出的动态内容以原文为准。
- 标题与来源不可省略，不使用诱导性标题；正文不得插入营销或导流内容。
- 不得改写政策原文含义，文号与发文机关须与官方一致；要点仅作辅助理解，须标注「以原文为准」。
- 组织信息由后台维护，变更需留操作记录；申请状态与后台审批状态保持一致。
- 证件与联系方式仅用于资格审核，实名信息仅本人可见。

## 业务闭环与状态约定

- **内容状态**：`草稿` → `待审核` → `已发布`，审核结果可为「通过」或「不通过」，已发布内容可「下架」；任何修改都会重新进入待审核。
- **审核环节**：编辑撰写 → 审核（通过 / 不通过）→ 自动发布。单层审核，不做多级流转，审核记录包含审核人、时间与意见。
- **加入组织**：`待审批` → `已通过` / `未通过`，承诺 5 个工作日内反馈。
- **活动报名**：`待确认` → `已确认` / `已取消`，后台可批量确认并导出名单。
- **角色管理**：角色可新增与删除，功能列表随六大模块同步（内容、审核与发布、轮播图、活动与报名、会员与组织、系统）；系统管理员为内置角色不可删除。
- **组织状态**：`已上线` / `已下线`；**项目状态**：`招商中` / `合作运营` / `招募中`。
- **前端只读**：小程序上的状态标签全部由后台驱动，用户侧不提供状态修改入口。
- **联系与留言**：项目、岗位、供需详情中的联系人默认遮蔽，登录后可见；提交留言或报名后由工作人员跟进，且不收取任何费用。
- **演示数据规模**：122 条内容（产业项目 42 / 信息 36 / 岗位 18 / 供需 14 / 活动 12）、18 个组织、27 份加入组织申请、23 条活动报名，日期集中在 2026 年。

## 技术实现

| 层 | 实现 |
| --- | --- |
| 结构 | 单文件 HTML，小程序每屏一个 `<section class="screen" data-screen="...">`，后台每个视图一个 `<section class="view" data-view="...">` |
| 样式 | 原生 CSS + 自定义属性，`tokens.css` → `base.css` → 页面级样式三层 |
| 脚本 | 原生 JavaScript（IIFE），无框架、无打包 |
| 图标 | JS 内联 SVG 字符串，零额外请求 |
| 依赖 | 无 `package.json`、无构建产物、无第三方库 |

- 交互由 `data-*` 属性 + 事件委托驱动，没有全局状态管理；小程序切屏会写入 hash，后台则读取 hash 直接打开对应视图，方便评审时按链接定位。
- 可访问性：`aria-label`、`role="button"` + `tabindex="0"`、`:focus-visible` 焦点环、方向键切屏、`prefers-reduced-motion` 降级。
- 适配：总览页 ≤900 单列；小程序外壳 1240 / 920 / 520 三档降级，520 以下隐藏页面目录；后台 1180 / 900 / 620 三档，900 以下侧栏收为 64px 图标栏。

## 已知限制

- 无后端与持久化：刷新即重置，提交、审核、上传、下载、搜索、分页均为前端模拟。
- 登录为演示态：任意密码可进入，不校验权限；角色与权限矩阵只用于展示权限设计。
- 简繁体为前端词典替换，覆盖 267 个常用字与 70 条词组，不处理多音字与语境歧义；仅静态界面元素生效。
- 宣传片未内置视频文件：点击播放会提示「演示环境未接入宣传片源」，正式上线由后台配置视频地址。
- 轮播图为手动切换，不做自动轮播；实际停留时长与动效由小程序端实现时确定。
- 所有数据与人物姓名均为虚构；政策原文为示意文本，正式发布前必须替换为官方文件并核对文号。
- 图片位置统一使用水乡波纹占位，未使用斗门区地图、区徽或任何官方标识。
- 设计总览页目前只保留头图与「待甲方确认」两部分；`overview.css` 中色板、字阶、图标、页面清单等样式已就绪，可继续补充对应章节。

## 参与贡献

1. 新增页面时先在 `src/assets/js/miniprogram.js` 的 `ORDER` 与 `NOTES` 中注册，说明面板会自动生成目录项。
2. 新增后台视图时在 `src/admin/index.html` 加 `<section class="view" data-view="…" data-title="…">`，侧栏按钮用同名 `data-view` 即可跳转。
3. 后台输出的动态内容在小程序端加 `data-dynamic`，避免被简繁转换改写。
4. 颜色、圆角、阴影一律引用 `tokens.css` 中的令牌，不在页面样式里写裸色值。
5. 新增图标加入 `src/assets/js/icons.js` 的图标表，统一 24×24、stroke 1.8、无填充。
6. 提交前确认三端在 1280 / 900 宽度下均可正常浏览，且键盘可完成主要操作。
